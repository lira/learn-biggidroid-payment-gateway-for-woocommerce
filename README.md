# BiggiDroid Payment Gateway for WooCommerce

A WordPress plugin that adds a "BiggiDroid Payment" gateway to WooCommerce. It integrates with WooCommerce (including WooCommerce Blocks) and provides admin settings for test/live mode and API keys. The project includes a JavaScript build setup using `@wordpress/scripts` for the checkout/block UI.
